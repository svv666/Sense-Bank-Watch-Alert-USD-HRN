# Sense-Bank-Watch-Alert-USD-HRN
Удобное приложение для Windows, которое в реальном времени показывает курсы доллара США в Sense Bank (онлайн, в отделении и по карте) и официальный курс Национального банка Украины. Программа работает в системном трее, строит наглядный график за 30 дней и вовремя предупреждает, если курс заметно изменился.
